國軍模擬器 3D 軍營 v0.11.3｜四支五人小隊 + 十名自主 NPC
====================================================

適用版本：v0.11.2 高畫質貼圖修復的「3D 軍營乾淨完整版」。
本檔是覆蓋更新包，不含 GLB、貼圖，也不包含舊的戰鬥系統。

安裝：
1. 先備份 GitHub 倉庫。
2. 解壓縮本 ZIP，將裡面的 index.html 和 src/ 資料夾依相同路徑上傳並覆蓋。
3. 等 GitHub Pages 部署完成後重新整理；iPhone 若仍載入舊版本可關閉分頁後重新開啟。
4. 可使用網址最後加 ?debug 顯示 30 人及四個小隊當下的活動站、狀態。

新規則：
- 總人數 30 人不變：10 個自由 NPC 保留原本個性、需求與社交判斷；另外 20 人分為四支五人小隊。
- 四隊從不同活動開始，依八項流程輪流轉站：操場跑步、集合場伏地挺身、拉單槓、靶場打靶、手榴彈投擲、障礙訓練、草地拔草、營舍周邊掃地。
- 行軍時由隊長規劃道路優先路線，其他四人沿隊長的移動軌跡保持近似 1-2-2 隊形。狹窄處會退為前後隊形。
- 到站後各自找訓練位置；場地容量不足則分批輪替，五人完成後再一起前往下一站。
- 四隊不能同時佔用同一訓練站；如果當站已有其他小隊，就跳至下一個可用站，避免整隊卡住等太久。
- 獨立 NPC 正在占用的單槓、靶位或手榴彈投擲位置會保留，隊伍只使用剩餘位置；其空出後可輪換使用。
- 尚無動畫的項目保持待機動作並顯示頭上活動名稱；沒有新增模型或破壞貼圖品質。

測試：
- JavaScript 語法檢查通過。
- 依現有 GLB 骨架與地圖配置模擬六分鐘，確認四隊與十名自由 NPC 可完成各自活動、沒有陷入建築或持續角色重疊。
- 特別測試 4 個單槓中 1 個被自由 NPC 占用：小隊先 3 人操作 / 2 人候補，再輪替完成。
- 尚未在實際 iPhone 與完整 WebGL 畫面上驗證，請先留意移動流暢度、隊形與 FPS。

限制及後續可調整處：
- 目前訓練內容為可視化小隊模擬，不是真正的打靶與投擲物理小遊戲。
- 障礙訓練、掃地、拉單槓、手榴彈投擲仍缺專用動畫。
- 1-2-2 是依行軍軌跡維持的近似隊形，路口或擁擠時會受避障影響。
- 八項活動是共通循環；若同一場地已有其他小隊，會自動調整下一站順序。
