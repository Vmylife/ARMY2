國軍模擬器｜v0.11.2 3D 軍營高畫質修正版

本版修正 v0.11.1 過度壓縮 GLB 貼圖造成的劣化：
建築 6 種：直接恢復 GitHub 原始 2048×2048 貼圖模型，無再次 JPEG 壓縮。
道具 16 種：恢復 2048×2048 解析度，JPEG 品質 94，4:4:4，保留原幾何、UV 與材質位置。
角色與 NPC 模型保留前一版的精簡資料，保留 30 人 AI、地圖與載入優化。
更新所有材質 GLB 與載入 JS 版本號至 112，避免 Safari 使用舊貼圖快取。

檔案使用方式：
A. 完整版 ZIP：在你備份後清空舊 GitHub 網站檔案，把 ZIP 解開的內容整批上傳到根目錄。
B. 覆蓋更新 ZIP：當你已經使用 v0.11.1 乾淨完整包時，保留其他檔案，依路徑覆蓋即可。

注意：全部 2048 材質會增加檔案大小與 GPU 貼圖記憶體，可能使首次載入變慢；這是畫質優先的保守修復。
「閃爍」如果仍存在，可能涉及原模型重疊表面 (Z-fighting) 或 iPhone Safari 取樣/渲染，需單獨定位。
