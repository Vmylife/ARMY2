《國軍模擬器》ARMY2 v0.11.6 — 動畫與場景編輯器同步修復

適用：Vmylife/ARMY2 現有 0.11.3 及後續版本（此包含 0.11.5 前置更新）。
上傳方式：ZIP 解壓後，保持資料夾層級，覆蓋 GitHub ARMY2 根目錄；勿直接上傳 ZIP。

1. 3D 動畫測試器：
  - 不再在選單顯示「未命名動作 5」（原始 GLB 片段沒有刪除，避免破壞模型）；
  - 「未命名動作 4」正式標示「敬禮」；
  - 新增「遊戲實際舉槍／射擊（程式動作）」：使用和主遊戲完全相同的 RIFLE_POSE、rifle.glb 以及後座和槍口火光；
  - 動畫測試網址：https://vmylife.github.io/ARMY2/animation-lab.html
2. NPC 坐椅子：
  - 套用使用者 2026-10-26 匯出的 Chair_Sit_Idle_M 校正：X=+0.04、Z=+0.52、Y=+0.17、yaw=0、速度1；
  - 左右兩個座位各自保留原本的橫向間距，座椅旋轉時偏移量也一併旋轉；
  - Y 高度僅作渲染修正，不影響人物腳下碰撞。
3. 場景編輯器：
  - 主遊戲和編輯器共用 src/map/activeCampLayout116.js；
  - 編輯器使用和主遊戲一致的 roadMesh104 與 lifeBounds107；
  - 重置編輯器本地版本快取，舊草稿保留在瀏覽器但不會自動覆蓋正式場景；
  - 含 v0.11.5 手榴彈三個投擲箱和雜草編輯器所需檔案（用戶先前的更新在 ARMY2 main 尚未出現）。
  - 場景編輯器網址：https://vmylife.github.io/ARMY2/editor.html

注意：沒有實際改寫 11.8MB 原始動畫 GLB，也不包含完整模型，只包含更新的程式與先前缺少的雜草模型。
