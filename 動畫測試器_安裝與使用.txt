《國軍模擬器》獨立 3D 動畫校正實驗室 v0.1

【用途】
- 獨立頁面，不必反覆修改主遊戲程式就能預覽／校正動畫。
- 預覽 1 名士兵、1 張長椅、1 座單槓、1 個手榴彈投擲箱。
- 使用您提供的 Meshy_AI_Little_Green_Cadet_All_Animations(1).glb（18 組動畫），另外提供程式產生的待機姿勢。
- 下拉選單會直接讀取 GLB 的動畫名稱；可播放、暫停、重播、循環與拖曳播放進度。
- 在設施旁調整士兵的 X/Z 位置、Y 高度、面向及動畫速度。
- 校正數值可以分「動畫＋設施」保存到當前瀏覽器、匯出 JSON 或重新匯入。
- 若新增了完整的同骨架動畫 GLB，可直接按「選擇新士兵 GLB」測試，不必改程式。

【安裝】
1. 此 ZIP 為『追加檔案』，不是全遊戲 ZIP。請先有 v0.11.2 或 v0.11.3 乾淨軍營版本。
2. 解壓 ZIP，保持資料夾路徑，把新增檔案上傳 GitHub 的 Vmylife/Army 儲存庫。
3. 不要將 ZIP 原檔直接當作網頁上傳；要上傳解壓縮後的內容。
4. 等 GitHub Pages 部署完畢，打開：
   https://vmylife.github.io/Army/animation-lab.html

【要注意】
- 目前只有 GLB 中實際存在的動畫。『掃地』『打籃球』『真正拉單槓』『丟手榴彈』等專用動畫尚未製作，此頁不會憑空補上。
- GLB 自訂匯入需包含士兵網格、骨架、動畫；只有動畫曲線、沒有網格的 GLB 暫不支援。
- 場景中的椅子、單槓、手榴彈箱是原本軍營的 3D 模型，由既有 assets/props 路徑載入；不用重新上傳。
- 首次打開頁面會額外下載約 11.8 MB 完整士兵動畫 GLB，加上三件道具；主遊戲不會載入這份測試模型。
- 匯出的 JSON 是校正結果，不會自動改動主遊戲。請回傳 JSON，就能依測得的相對站位整合主遊戲。
- 這裡能獨立驗證動作預覽和站位，但目前還未提供真正的動畫檔案製作／骨架編輯器。

【建議的第一個測試流程】
1. 打開 animation-lab.html。
2. 動畫選「坐椅子（Chair_Sit_Idle_M）」，設施選「椅子」。
3. 觀察椅座、臀部與腳的位置，調整「左右」「前後」「高度」「朝向」至視覺正確。
4. 按「儲存本動作校正」，再按「匯出全部設定 JSON」。
5. 把 JSON 傳回對話，我再整合到軍營。
