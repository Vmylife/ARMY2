ARMY2 v0.11.15: 椅子/投擲箱座標來源統一、中文動畫名稱修正。
基礎版本：v0.11.14（請先安裝 v0.11.13 的新版動畫/地圖，再安裝 v0.11.14）。

1. 讓動畫測試器與主遊戲共用 src/characters/fixturePose115.js 內唯一座標轉換函式。
2. 手榴彈直接以投擲箱中心和 p.yaw 作為原點及局部座標旋轉角度，不再使用 v0.11.14 的紅圈平均偏移。
3. 自由 NPC/四支小隊使用相同函式、相同兩組獨立動畫校正值，隨機選擇機制保留。
4. 椅子與打瞌睡也使用共用的轉換函式，保留一椅一人座位鎖。
5. 動畫測試器恢復手榴彈兩動作中文名稱、切換動畫時自動選擇投擲箱。
6. 模型、地圖、動畫 GLB 均不變動。

注意：固定校正來自你匯出的 JSON；當前測試器上的本機儲存校正仍會優先於預設值顯示。
若椅子仍有偏差，需另外排查主遊戲/測試器角色 GLB 骨架姿勢差異及模型定位；不是繼續亂改偏移數值。

安裝：解壓後按同路徑覆蓋 ARMY2，部署後強制重新整理動畫測試器與主遊戲。
驗證：已做 Node 語法與純函式一致性測試，未在 iPhone 實測可視效果。
