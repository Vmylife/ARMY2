國軍模擬器 ARMY2 v0.11.16 — NPC 等候區、座椅尋路與動畫測試器

基於 v0.11.15，覆蓋到 ARMY2 專案根目錄。只有有修改的程式／網頁檔案，不包含大型 GLB。

1. 手榴彈區：四支小隊使用同一訓練場預約。將隊伍集合點與五名士兵的等候位置搬到西南紅圈（安全圍欄內）：(-38.8,-29.4)、(-37.4,-29.4)、(-36.0,-29.4)、(-38.2,-30.8)、(-36.8,-30.8)。投擲站位不受影響，仍由每個箱子的座標與 yaw，以及你的動畫校正 JSON 換算。
2. 增加從投擲場退出的出口路點、場地重用間隔、卡死超時釋放與隊伍離場避讓，改善長時間累積堵塞。
3. 坐椅子／坐椅子打瞌睡：先到椅子前方可通行的接近點，然後切入校正後的座位，保留一椅一人。若接近處被堵住，偵測沒有實際前進後取消本次行動，不再無限原地走。
4. 動畫測試器新增哨口建築和雜草 GLB；選擇站哨（主遊戲目前是立正 Idle）可在哨口前調整，選擇 Pull_Radish 則自動切到雜草測試。舊動畫全部保留。
5. 最新 Army_軍營編輯配置_2026-10-26 (5).json 的六項更動已寫入 src/map/layout126.js，主遊戲和地圖編輯器皆共用。
6. 已加快各個入口程式的快取版本。

驗證：node --check 語法通過；地圖內三個箱子 * 兩種校正皆跟著箱子旋轉且各站點碰撞判定通過；紅圈五個等待點可通行；10 張椅子的接近點可通行；30 人模擬 6 分鐘。
限制：此環境的瀏覽器禁止連到 localhost，本次沒有宣稱已通過 iPhone 3D 實機視覺驗證。
