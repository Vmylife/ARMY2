Army v0.11.5｜手榴彈投擲場、四人跟隊平滑化、雜草編輯器素材

適用：v0.11.3 四小隊 30 人軍營，且已安裝 v0.11.2 高畫質模型修復。
此 ZIP 只包含更動檔，不包含主角或既有建築 GLB；請依資料夾路徑覆蓋。

1. 使用 2026-10-26 軍營編輯器輸出 JSON（新增兩個手榴彈箱、兩個沙包，移動原手榴彈箱和沙包）。
2. 投擲位置依三個手榴彈箱動態配置，在箱體南方約 1.52 單位，面向 +Z（操場內側）。
3. 兩名隊員到東側等待區，三名先投擲，完成後輪換；不把自由 NPC 佔用的位置強制清空。
4. 列隊跟隨改平滑速度與固定走路動畫，避免接近隊形點時頻繁切換 Idle/Walking。
5. 地圖編輯器「新增物件」新增雜草，使用你上傳的 GLB；預設不自動在主地圖散布雜草。
6. 此次未改獨立動畫測試器、建築模型或貼圖。

備註：在編輯器選「道具／裝飾」→「雜草」→「新增到鏡頭中心」。
如你的編輯器舊配置是存在瀏覽器 localStorage，本版使用新 key，以避免舊資料覆蓋這次軍營配置。

驗證：JS 語法、GLB 結構、配置數量與 JSON 位置比對；尚未在 iPhone 實機完整 3D 渲染與 FPS 測試。
